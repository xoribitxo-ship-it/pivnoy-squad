# Пивной Сквад — сайт Minecraft-сервера

Живой сайт: https://pivnoy-squad.vercel.app/

Одностраничный статический сайт без сборки: вся разметка, стили и скрипт темы находятся в `index.html`.

## Структура

| Путь | Назначение |
| --- | --- |
| `index.html` | Вся страница: HTML + `<style>` + SVG ночной сцены + скрипты темы и статуса |
| `undead-sprite.png` | Скин Undead_xD, отдаётся по `/undead-sprite.png` |
| `assets/skins/morethan-sprite.png` | Копия скина MoreThanSkill (в HTML он вшит как base64) |
| `assets/fonts/` | Локальные woff2 `Press Start 2P` (кириллица и латиница) |
| `assets/favicon.svg`, `favicon-32.png`, `apple-touch-icon.png` | Иконки сайта |
| `assets/og-image.png` | Превью 1200×630 для Discord и соцсетей |
| `robots.txt`, `sitemap.xml` | Индексация |
| `404.html` | Страница «не найдено» в стиле таверны, отдаётся Vercel автоматически |
| `vercel.json` | Заголовки безопасности и кэш ассетов |

Светлая сцена таверны — CSS-арт в диагональной 3/4-композиции: наклонённые полки с двумя рядами бутылок, стойка и дощатый пол в общем `.lower`, вертикальные фигурки и кружки, фонари на цепях, стол на переднем плане и бочка у стойки. Тёмная тема — инлайновый SVG: хижина на холме у кубического леса, кривая вывеска и одна бочка (отсылка к «Летописи»).

## Статус сервера

Под адресом подключения есть полоска со статусом. Данные берутся на клиенте из публичного API `https://api.mcsrvstat.us/3/BeerSquad.aternos.me` (CORS открыт, ключ не нужен), обновление раз в минуту и при возврате на вкладку.

Состояния: `СЕРВЕР ОНЛАЙН · N/M` со списком ников, `СЕРВЕР СПИТ` (Aternos отдаёт заглушку «This server is offline»), `СЕРВЕР ОФЛАЙН`, `СТАТУС НЕДОСТУПЕН` при ошибке сети. Полоска всегда одной высоты, длинный список ников обрезается многоточием — макеты не прыгают.

## Локальный просмотр

```powershell
npx --yes serve . -l 3000
```

Затем открыть http://localhost:3000. Либо просто открыть `index.html` в браузере.

Если npm не видит сеть, используется локальный прокси:

```powershell
$env:npm_config_proxy = "http://127.0.0.1:12334"
$env:npm_config_https_proxy = "http://127.0.0.1:12334"
```

## Деплой

Проект размещён на Vercel как статика и связан с GitHub-репозиторием `xoribitxo-ship-it/pivnoy-squad` (ветка `main`).

Любой `git push origin main` запускает сборку автоматически — отдельный деплой не нужен. Ручной вариант на случай сбоя:

```powershell
npx --yes vercel@latest --prod --yes
```

Адрес `/undead-sprite.png` зашит в `index.html` — при переносе картинки в подпапку нужно обновить и разметку.

## Известные особенности

- Заголовки — локальный `Press Start 2P`, основной текст — явный системный моноширинный стек. Пиксельный `Rubik Pixels` для основного текста не используется: при 15px он плохо читается.
- Адаптив: `max-width: 480px` (телефон), `481–820px` (планшет), выше — десктоп; плюс `clamp()`.
- Тёмная тема заменяет интерьер таверны ночной сценой с хижиной. Пока игрок не выбрал тему вручную, сайт берёт её из системных настроек (`prefers-color-scheme`) и следит за их изменением; после клика по переключателю выбор сохраняется в `localStorage` под ключом `ps-theme` и перекрывает системный.
- Кнопка «Поделиться» рядом с Discord использует системное меню (`navigator.share`), а там, где его нет, копирует ссылку в буфер. Кнопки одинаковой ширины, поэтому подпись «СКОПИРОВАНО» не двигает вёрстку.
- Внешних зависимостей нет: шрифты, иконки и превью лежат в репозитории. Единственный внешний запрос — статус сервера через `api.mcsrvstat.us`; без сети страница работает как обычно.
