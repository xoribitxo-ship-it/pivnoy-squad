# Пивной Сквад — сайт Minecraft-сервера

Живой сайт: https://pivnoy-squad.vercel.app/

Одностраничный статический сайт без сборки: вся разметка, стили и скрипт темы находятся в `index.html`.

## Структура

| Путь | Назначение |
| --- | --- |
| `index.html` | Вся страница: HTML + `<style>` + скрипт переключения темы |
| `undead-sprite.png` | Скин Undead_xD, отдаётся по `/undead-sprite.png` |
| `assets/skins/morethan-sprite.png` | Копия скина MoreThanSkill (в HTML он вшит как base64) |

Иллюстрация таверны — не картинка, а CSS-арт (полки, бутылки, фигурки, кружки, пол). Отдельного файла с ней нет.

## Локальный просмотр

```powershell
npx --yes serve . -l 3000
```

Затем открыть http://localhost:3000. Либо просто открыть `index.html` в браузере.

Если npm не видит сеть, используется локальный прокси:

```powershell
$env:npm_config_proxy = "http://127.0.0.1:12334"
$env:npm_config_https_proxy = "http://127.0.0.1:12334"
```

## Деплой

Проект размещён на Vercel как статика. Адрес `/undead-sprite.png` зашит в `index.html` — при переносе картинки в подпапку нужно обновить и разметку.

## Известные особенности

- В Google Fonts запрошен `Rubik Pixel`, но существует `Rubik Pixels`; сейчас основной текст падает в системный `monospace`.
- Адаптив — один брейкпоинт `max-width: 480px` плюс `clamp()`.
- Тёмная тема скрывает фигурки и обстановку таверны, оставляя ночной пейзаж.
