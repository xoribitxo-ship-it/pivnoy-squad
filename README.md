# Пивной Сквад — сайт Minecraft-сервера

Живой сайт: https://pivnoy-squad.vercel.app/

Одностраничный статический сайт без сборки: вся разметка, стили и скрипт темы находятся в `index.html`.

## Структура

| Путь | Назначение |
| --- | --- |
| `index.html` | Вся страница: HTML + `<style>` + SVG ночной сцены + скрипты темы |
| `undead-sprite.png` | Скин Undead_xD, отдаётся по `/undead-sprite.png` |
| `assets/skins/morethan-sprite.png` | Копия скина MoreThanSkill (в HTML он вшит как base64) |
| `assets/skins/head-*.png` | Головы для блока «Кто за стойкой»: `head-undead`, `head-morethan`, `head-stren47`, `head-shkonka` (128×128, PNG с палитрой) |
| `assets/fonts/` | Локальные woff2 `Press Start 2P` (кириллица и латиница) |
| `assets/shots/` | Четыре скриншота с сервера для галереи «Наши края» (JPEG 16:9, 20–45 КБ) |
| `assets/favicon.svg`, `favicon-32.png`, `apple-touch-icon.png` | Иконки сайта |
| `assets/og-image.png` | Превью 1200×630 для Discord и соцсетей (собрано из `assets/shots/aurora.jpg`) |
| `robots.txt`, `sitemap.xml` | Индексация |
| `404.html` | Страница «не найдено» в стиле таверны, отдаётся Vercel автоматически |
| `vercel.json` | Заголовки безопасности и кэш ассетов |

Светлая сцена таверны — CSS-арт (деревянная стена в тёплом свете, полки с двумя рядами бутылок, фонари на цепях, фигурки, кружки, стойка, бочки). В светлой сцене два котика: чёрно-белый на правой полке и рыжий на стойке. Они лежат, встают и идут лакать пиво — чёрный к кружке на полке, рыжий к кружке Undead_xD. Анимация зациклена на 18 секунд, у рыжего задержка 3 секунды; при `prefers-reduced-motion: reduce` котики просто стоят. Тёмная тема — инлайновый SVG: хижина на холме у кубического леса, кривая вывеска и одна бочка (отсылка к «Летописи»).

## Галерея

Секция `#mir` («Наши края») — четыре реальных скриншота с сервера: широкий кадр с полярным сиянием и три в ряд, оформленные как картины в деревянных рамах. Подписей под кадрами нет. По клику кадр открывается на весь экран: стрелки и Esc (есть и кнопки по краям), фокус возвращается на выбранный кадр, фон страницы не прокручивается. Без JavaScript каждая картинка открывается как обычная ссылка на JPEG.

Чтобы добавить кадр: положите JPEG 16:9 (примерно 1400×788, 20–50 КБ) в `assets/shots/`, продублируйте `<figure class="shot">` в секции `#mir` и не забудьте обёртку `<a class="shot-link" href="…">` — на ней держится лайтбокс.

## Состав и правила

Секция `#squad` («Кто за стойкой») — четыре карточки с головами скинов: Undead_xD (создатель, отмечен звёздочкой), MoreThanSkill (гл. админ), St_Ren47 (игрок · билдер) и shkonka (просто имба). Головы — кропы: Undead_xD и MoreThanSkill вырезаны из спрайтов в сцене, shkonka — из присланного владельцем скриншота, голова St_Ren47 собрана из основного и внешнего слоёв его скина 64×64. Картинки 128×128, в CSS включён `image-rendering: pixelated`; при замене скина обновите файл в `assets/skins/` с тем же именем.

Секция `#rules` («Устав таверны») — двенадцать коротких пунктов в карточках с номерами. Нумерация на CSS-счётчике, так что новый пункт достаточно вставить `<li>` — номер пересчитается сам.

## Локальный просмотр

```powershell
npx --yes serve . -l 3000
```

Затем открыть http://localhost:3000. Либо просто открыть `index.html` в браузере.

Если npm не видит сеть, используется локальный прокси:

```powershell
$env:npm_config_proxy = "http://127.0.0.1:12334"
$env:npm_config_https_proxy = "http://127.0.0.1:12334"
```

## Деплой

Проект размещён на Vercel как статика и связан с GitHub-репозиторием `xoribitxo-ship-it/pivnoy-squad` (ветка `main`).

Любой `git push origin main` запускает сборку автоматически — отдельный деплой не нужен. Ручной вариант на случай сбоя:

```powershell
npx --yes vercel@latest --prod --yes
```

Адрес `/undead-sprite.png` зашит в `index.html` — при переносе картинки в подпапку нужно обновить и разметку.

## Известные особенности

- Заголовки — локальный `Press Start 2P`, основной текст — явный системный моноширинный стек. Пиксельный `Rubik Pixels` для основного текста не используется: при 15px он плохо читается.
- Адаптив: `max-width: 480px` (телефон), `481–820px` (планшет), выше — десктоп; плюс `clamp()`.
- Тёмная тема заменяет интерьер таверны ночной сценой с хижиной. Пока игрок не выбрал тему вручную, сайт берёт её из системных настроек (`prefers-color-scheme`) и следит за их изменением; после клика по переключателю выбор сохраняется в `localStorage` под ключом `ps-theme` и перекрывает системный.
- Кнопка «наверх» появляется после 600 px прокрутки, скип-линк ведёт сразу к сцене. Все анимации (фонари, пар, звёзды, дым, покачивание вывески) отключаются при `prefers-reduced-motion: reduce`.
- Внешних зависимостей нет: шрифты, иконки и превью лежат в репозитории. Внешних запросов нет: шрифты, иконки и превью лежат в репозитории; без сети страница работает как обычно.
