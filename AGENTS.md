# AGENTS.md

Одностраничный статический сайт Minecraft-сервера «Пивной Сквад».
Живой адрес: https://pivnoy-squad.vercel.app/

## Главное

- **Нет сборки и фреймворка.** Рядом с `index.html` всегда правь сам `index.html`: HTML, CSS и JS темы лежат в нём инлайн. Не добавляй Vite/React без явного запроса.
- **Не заменяй графику.** Светлая сцена таверны — CSS-арт (деревянная стена, полки с бутылками, фонари на цепях, бочки у стойки), тёмная — инлайновый SVG `.night` (хижина на холме, кривая вывеска, одна бочка). Не подменяй их растровыми картинками и не добавляй стоковые ассеты.
- Скин MoreThanSkill вшит в HTML как base64. Его копия — `assets/skins/morethan-sprite.png`. Скин Undead_xD лежит в корне и грузится по `/undead-sprite.png` — этот путь зашит в разметке. Спрайты разной пропорции (32×48 и 128×256), поэтому `.skin` масштабируется по высоте с `max-width:none`: если вернуть `max-width:100%`, широкий спрайт MoreThanSkill ужмётся по ширине и повиснет ниже Undead_xD — головы перестанут быть на одном уровне.
- Шрифты локальные (`assets/fonts/`), Google Fonts не используется. `Press Start 2P` — только заголовки; основной текст — системный моноширинный стек. Не возвращай `Rubik Pixel(s)` для body: проверено, при 15px текст плохо читается.
- Ночная сцена имеет `viewBox="0 0 900 470"` и `preserveAspectRatio="xMidYMax slice"` — важные объекты держи в центральной половине ширины, иначе их срежет на телефоне.
- Тема хранится в `localStorage` (`ps-theme`), класс `dark` ставится на `<html>`; в CSS поэтому селекторы `html.dark body`, а не `body.dark`. Если сохранённого выбора нет, тема берётся из `prefers-color-scheme`; сохранённый выбор всегда важнее системного.
- `404.html` — отдельная страница в том же стиле (Vercel отдаёт её сама), тему берёт так же, переключателя на ней нет.
- Статус сервера — блок `.status` под адресом IP. Данные тянет `fetch` к `api.mcsrvstat.us` (v3), состояния задаются атрибутом `data-state` (`online` / `sleep` / `offline` / `unknown`). Не увеличивай высоту блока от состояния к состоянию: список ников обрезается многоточием, иначе вёрстка прыгает. Время последней проверки — плашка `.status-time` в той же строке, что и состояние; при неудачном запросе показывается последний удачный ответ из `localStorage` (`ps-srv`) с пометкой «кэш», поэтому блок не сваливается в «недоступен» при каждом сбое сети.
- Галерея `#mir` («МИР СКВАДА» / «НАШИ КРАЯ») — реальные скриншоты с сервера из `assets/shots/` (JPEG 16:9, ~1400×788, по 20–45 КБ). Кадры оформлены как картины в рамах, первый — широкий. Подписей под кадрами нет — так попросил владелец; не придумывай названий мест, которых нет, и не возвращай подписи самовольно. Клик по кадру открывает лайтбокс (`#lightbox`): стрелки, Esc, свайп-кнопки, фокус возвращается на кадр. Каждая картинка обёрнута в `<a href>` на исходник — без JS кадр просто открывается в новой вкладке.
- `assets/og-image.png` (1200×630) собирается вручную из `assets/shots/aurora.jpg`: верх — фото, низ — деревянная плашка с заголовком и IP. При смене главного кадра обновляй превью, иначе в Discord показывается старое.
- Мелочи, которые легко сломать: кнопка «наверх» `.to-top` появляется после 600px прокрутки; скип-линк `.skip` ведёт на `#taverna` (у секции `tabindex="-1"`); у всех анимаций (фонари, пар, звёзды, дым, вывеска, кнопка «наверх») есть отключение в `@media(prefers-reduced-motion:reduce)` — сохраняй это.

## Проверка

```powershell
npx --yes serve . -l 3000
```

Открыть http://localhost:3000. Автотестов нет; проверяй вручную обе темы, ширины 320 / 480 / 820 / десктоп, кнопку копирования IP и сохранение темы после перезагрузки. Дополнительно: клик по кадру галереи (лайтбокс, стрелки, Esc), кнопка «наверх», статус при недоступном `mcsrvstat`.

Для проверки удобно делать временные копии страницы в корне — `_light.html`, `_dark.html` (принудительная светлая/тёмная тема) и `_test-*.html` (харнессы в iframe: мобильные ширины, клики, измерения). Они в `.gitignore`, в коммит не попадают; после проверки удаляй.

## Сеть

Внешний доступ на этой машине идёт через прокси `http://127.0.0.1:12334`. Для npm:

```powershell
$env:npm_config_proxy = "http://127.0.0.1:12334"
$env:npm_config_https_proxy = "http://127.0.0.1:12334"
```

Для git: `git config --global http.proxy http://127.0.0.1:12334`.

## Git и деплой

- Git — портативный, `C:\Users\user\AppData\Local\Programs\PortableGit2\cmd` (уже в PATH пользователя).
- Ветка `main`, коммиты короткие и по одной правке.
- Деплой на Vercel статикой, репозиторий GitHub `xoribitxo-ship-it/pivnoy-squad` связан с проектом: пуш в `main` деплоит сам. Не создавай новый проект Vercel молча: адрес `pivnoy-squad.vercel.app` должен сохраниться.
- Пуш сам по себе домен не переключает: после `vercel rollback` он остаётся привязан к старому деплою. Поэтому после пуша, если прод не обновился: `npx --yes vercel@latest --prod --yes`, затем `npx --yes vercel@latest alias set <прод-URL> pivnoy-squad.vercel.app`, и проверить, что файл на проде байт-в-байт совпадает с локальным (`curl` + SHA256).
- Прямой доступ к `*.vercel.app` нестабилен (иногда `000` по таймауту), `github.com` и `api.vercel.com` работают. Ответ API Vercel можно смотреть скриптом с токеном из `%APPDATA%\com.vercel.cli\Data\auth.json`.
